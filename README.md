## 📖 About The Project

The **Meteorology Study Hub** is an interactive web-based learning and analysis platform designed around the study of atmospheric science.

What started as a simple HTML learning project evolved into a functional **meteorological workstation** containing weather tools, atmospheric calculations, observation logging, METAR decoding, cloud identification, quizzes, formulas, live weather data, and interactive charts.

The project is also an experiment in combining my academic background in **Meteorology** with my growing skills in **Web Development and Technology**.

### 🧮 Relative Humidity Calculator

A dedicated calculator allows users to determine relative humidity using:

**RH = (e / es) × 100**

Where:

* `RH` = Relative Humidity
* `e` = Actual Vapour Pressure
* `es` = Saturation Vapour Pressure

The calculator also provides the calculation result and breakdown.

---

### 📝 Weather Observation Log

Users can record weather observations including:

* Temperature
* Atmospheric pressure
* Relative humidity
* Wind speed
* Wind direction
* Visibility
* Rainfall
* Cloud cover

Observation records are stored locally in the browser and can be exported for further analysis.

### ✈️ METAR Decoder

The METAR tool provides a simplified interpretation of common METAR weather reports.

It can decode information such as:

* Station identifier
* Observation time
* Wind direction
* Wind speed
* Visibility
* Cloud conditions
* Temperature
* Dew point
* Atmospheric pressure

This feature is particularly useful for learning the structure of aviation weather observations.

### 📐 Meteorological Formula Hub

The Formula Hub provides quick access to important atmospheric equations.

Current formulas include:

#### Relative Humidity

`RH = (e / es) × 100`

#### Mixing Ratio

`r = εe / (p − e)`

#### Potential Temperature

`θ = T(p₀ / p)ᵏ`

#### Dry-Air Density

`ρ = p / (RᵈT)`

#### Hydrostatic Equation

`dp/dz = −ρg`

#### Hypsometric Equation

`Δz = (RᵈTᵥ / g) ln(p₁ / p₂)`

#### Zonal Wind Component

`u = −V sin θ`

#### Meridional Wind Component

`v = −V cos θ`

The Formula Hub includes search and category filtering to make equations easier to find.
